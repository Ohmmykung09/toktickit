# Lab 2 AI Use and Reflection

## AI Tool Used

I used Codex as an AI specification and coding assistant during Lab 2. I used it to refine the engineering contract before implementation, divide the sprint into focused Issues, implement each vertical slice, interpret reviewer feedback, and prepare test and delivery evidence.

I remained responsible for approving the specification, checking changed files, running commands locally, reviewing API and database behaviour, and deciding whether evidence satisfied the lab requirements.

## My Reflection

AI helped me move from a broad stakeholder request to small, reviewable engineering tasks. The strongest prompts named the current Issue, the applicable contract documents, what must be tested, and the scope that must not be implemented. Reviewer comments were especially useful because I could turn one concrete observation into a focused regression test.

I did not rely on an AI claim that a feature was complete. I reviewed the generated changes, verified endpoint and database behaviour, ran tests and builds, and recorded what still requires final-main screenshot evidence. The final responsibility for the specification, implementation, and submitted evidence remains mine.
